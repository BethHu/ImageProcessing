# myAlg 使用流程指南

> 更新：添加了 Butterworth 高通滤波器与高斯高通滤波器功能，并完善预览与逆变换、保存的工作流程。

## 环境准备
- 操作系统：Windows
- 开发工具：Visual Studio（项目包含 `vc100` 线索，推荐 VS2010 及以上）
- 打开工程：使用 `myAlg.sln` 解决方案构建并运行

## 功能概览
- 频域分析：支持二维 DFT、谱图显示（居中频谱）
- 滤波器类型：
  - 理想高通（Ideal High-Pass）
  - 巴特沃斯高通（Butterworth High-Pass）
  - 高斯高通（Gaussian High-Pass）
- 预览：在居中频谱上显示滤波后的幅度谱
- 逆变换：将滤波结果做 IDFT 并归一化到 [0,255]
- 保存：在主界面通过 “Write” 保存重建图像

## 使用流程
1. 构建并运行工程：打开 `myAlg.sln`，编译并启动程序。
2. 打开图像：在主界面载入待处理图像。
3. 频谱分析：进入频域分析（FourierSpectrumDlg），计算并查看幅度谱（居中频谱）。
4. 进入滤波：打开理想滤波对话框（IdealFilterDlg）。
5. 选择滤波器类型：
   - 理想高通 / 巴特沃斯高通 / 高斯高通（单选，互斥）。
6. 设置参数：
   - 截止频率：通过滑块联动 Edit（范围建议 [0.01, 0.49]）。
   - 巴特沃斯阶数：仅在巴特沃斯模式下可设置（建议范围 [1, 10]）。
7. 预览效果：点击 “预览”，显示在居中频谱上的滤波幅度图，便于调参。
8. 应用并逆变换：点击 “确定” 应用滤波，进入逆变换对话框（InverseDFTDlg），执行 IDFT 将结果还原至空间域，并自动归一化。
9. 保存结果：返回主界面，在输出图区域确认效果，使用 “Write” 保存重建图像。

## 参数与实现细节
- 居中频谱：滤波掩模在居中坐标系构建，应用后会还原为非居中再做 IDFT。
- 巴特沃斯高通：\( H(u,v) = \frac{1}{1 + (\frac{D_0}{D(u,v)})^{2n}} \)；可调阶数 \(n\)。
- 高斯高通：\( H(u,v) = 1 - e^{-\frac{D(u,v)^2}{2D_0^2}} \)。
- 亮度增强（High-boost）：滤波时采用系数（默认约 1.2）以改善重建亮度和细节保留。
- 归一化：IDFT 后执行最小-最大归一化至 [0,255]，避免重建图偏暗或全黑。

## 常见问题
- 预览变化不明显：检查是否选择了正确的滤波器类型，截止频率是否太小或太大。
- 重建图像偏暗或全黑：适当提高截止频率或确认图像具有足够高频；程序已做归一化处理。
- 保存未生效：请确保已执行逆变换并在主界面使用 “Write”。
