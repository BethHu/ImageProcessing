# Wedge 条纹去噪滤波使用说明

> 本说明文档介绍新增加的 “Wedge stripe removal” 频域去条纹滤波功能，包括算法思路、操作流程以及参数说明。

## 1. 功能简介

在某些成像系统（医学影像、工业 CT、射线成像等）中，图像上会出现一组沿固定方向排列的条纹噪声。这类噪声在频域中通常表现为：

- 以某一主方向为中心，沿径向分布的一簇高能量谱线；
- 在居中频谱上，对应于一条或一扇“楔形（wedge）”高能区域；
- 有时在 180° 对称方向上也会出现一簇共轭条纹。

`Wedge` 滤波器的核心思想是：

- 在 **居中后的 DFT 频谱** 上，按角度选取一个（或两个对称的）楔形区域；
- 在该楔形角度范围内，将频谱系数置零（或强烈抑制），其它区域尽量保持不变；
- 最后将频谱中心移回原位置并做 IDFT，得到条纹被抑制后的图像。

这样可以在尽量保留整体结构的同时，针对性地消除沿某一固定方向的条纹噪声。

## 2. 使用流程

下面以程序主界面的 `Wedge` 按钮为入口，给出完整流程说明。整体流程与理想高通/巴特沃斯高通的频域流程类似：

1. **启动程序**  
   - 使用 Visual Studio 打开 `myAlg.sln` 并以 Debug 或 Release 配置编译运行。

2. **载入输入图像**  
   - 在主界面选择输入图像（与原有频域操作一致）。

3. **进入频谱分析**  
   - 点击对应按钮进入 `FourierSpectrumDlg`：
     - 程序会计算二维 DFT；
     - 显示 **居中后的幅度谱图** 以便观察频域结构。

4. **从频谱进入 Wedge 滤波**  
   - 在频谱对话框中点击继续/下一步，程序关闭频谱窗口并弹出 **Wedge stripe removal** 对话框（`CWedgeFilterDlg`）。

5. **在 Wedge 对话框中设置参数并预览**  
   Wedge 对话框包含以下核心控件：

   - 起始角 `start angle`（度）
   - 结束角 `end angle`（度）
   - 半径 `radius`（像素）
   - 半径滑条（0–100，对应 0–最大可选半径）
   - 自动检测角度按钮 `Detect`（可选）
   - 预览按钮 `Preview`

   使用步骤：

   1. **（可选）自动检测条纹主方向**  
      - 点击 `Detect`：程序会在当前居中频谱上对各个角度做能量统计，估计条纹噪声主方向角度 `θ*`；
      - 检测结果会以弹窗提示，并自动填入起始角/结束角（默认 `θ* ± 10°`）。

   2. **手动微调角度范围**  
      - 根据频谱观察结果，可手动修改 `start angle` 与 `end angle`：
        - 两者的中值作为中心角 `centerAngle`；
        - 半差作为半角 `halfAngle`，程序会自动限制在 `[0.5°, 90°]` 以内。

   3. **设置半径与滑条联动**  
      - `radius` 表示楔形区域从频谱中心向外的最大作用半径（像素）：
        - `radius <= 0` 表示不限半径（作用到频谱边缘）；
        - `radius > 0` 时，仅在距离中心小于等于该半径范围内执行楔形置零，其它半径位置保持原频谱。
      - 滑条范围为 0–100，会自动映射到 `[0, maxRadius]`：
        - `maxRadius` 约为 `min(width, height) / 2`；
        - 拖动滑条会实时更新 `radius` 文本；
        - 修改 `radius` 文本也会反向驱动滑条，二者始终保持一致。

   4. **点击 `Preview` 预览频谱效果**  
      - 程序会：
        1. 按当前 `start/end angle` 与 `radius` 构造楔形掩模；
        2. 在居中 DFT 上将该楔形范围内系数置零；
        3. 将结果再居中，计算并显示滤波后的幅度谱；
      - 预览窗口标题形如：
        - `Wedge preview: theta = 100.5, half = 10.0 (symmetric)`
        - 表示中心角度和半角大小，以及是否对称处理。

6. **应用滤波并进入逆变换**  
   - 在预览满意后点击 `OK`：
     - 对话框内部会再次根据当前参数执行一次 Wedge 掩模构造，得到最终的过滤后 DFT（非居中）；
     - 若生成失败（例如 DFT 尚未计算），会给出错误提示并留在当前对话框。
   - 成功后程序进入 `InverseDFTDlg`：
     - 使用 Wedge 过滤后的 DFT 做 IDFT，得到重建图像；
     - 按既有流程执行归一化与显示。

7. **在主界面查看并保存结果**  
   - 逆变换结束后返回主界面：
     - 输出图窗口显示 Wedge 去条纹后的图像；
     - 使用主界面的 `Write` 功能保存结果图像到文件。

## 3. 参数说明与实现细节

### 3.1 角度坐标系

- 频谱在 DFT 居中后，以图像中心 `(cx, cy)` 为原点：
  - 对任意频率点 `(x, y)`，令 `dx = x - cx`, `dy = y - cy`；
  - 使用 `atan2(dy, dx)` 计算角度，范围为 `[-π, π]`；
  - 再转换为度数：`theta = atan2(dy, dx) * 180 / π`，范围为 `[-180°, 180°]`。
- 中心角 `centerAngle` 和半角 `halfAngle` 均在度数域中计算，并通过 `angNormDeg()` 保持在 `[-180°, 180°]` 范围内。

### 3.2 楔形掩模逻辑

设：
- `center` = 归一化后的中心角度；
- `half` = 半角（非负）；
- `theta` = 当前频率点角度；
- `d1 = |angNormDeg(theta - center)|`；
- `d2 = |angNormDeg(theta - (center + 180°))|`（当启用对称模式时）；

则：

- 点在楔形内的条件：
  - `inWedge = (d1 <= half) || (d2 <= half)`；
- 半径约束：
  - 若 `wedgeRadius > 0` 且 `r = sqrt(dx² + dy²) > wedgeRadius`，则该点不受楔形抑制；
- 实际操作：
  - 若 `inWedge` 且 `r <= wedgeRadius`（或未设置半径限制），则对应 DFT 系数置为 `0 + 0i`；
  - 否则保持原始频谱值不变；
  - DC 分量（中心点）始终原样保留。

### 3.3 自动角度检测

- 通过对居中 DFT 的能量按角度统计实现：
  - 在一定半径范围 `[rMin, rMax]` 内遍历频谱点；
  - 计算每个点的 `theta`，将其能量 `|F(u,v)|` 累加到对应角度 bin；
  - 最终取能量最大的 bin 对应的角度作为条纹主方向估计值；
- 检测到的角度将通过对话框弹窗提示，并自动填入起止角（默认 ±10°）。

## 4. 与原有高通滤波器的关系

- 流程层面：
  - `InputDlg → FourierSpectrumDlg → WedgeFilterDlg → InverseDFTDlg → 主界面输出`；
  - 与 Ideal/Butterworth/Gaussian 高通的 DFT-Filter-IDFT 流程保持一致，便于集成与维护。
- 实现层面：
  - Wedge 滤波直接操作复数 DFT 系数，不改变原有高通滤波模块；
  - 使用相同的 `CFourierTransform` 和 `CImageDisplay` 工具链进行频谱显示和逆变换。

## 5. 已知注意事项

- **编码问题**：
  - 为避免 Visual Studio 在 GB2312 编码下出现乱码，本模块相关的 C++ 源文件（尤其是 `WedgeFilterDlg.cpp/.h`）中已全部使用英文字符串与注释；
  - 文档（本 README）采用 UTF‑8 编码，在 GitHub 上浏览不会有问题。
- **条纹未完全去除**：
  - 可尝试：
    - 调整角度范围（扩大半角或手动修正中心角）；
    - 调整半径，使楔形覆盖到条纹对应的频率位置；
    - 多次尝试 `Detect` 获取更合适的初始角度。
